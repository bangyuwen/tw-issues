## Why

The published EZ WAY page is useful as a public process explainer, but it is not an unmistakable public issue: readers cannot easily tell what dispute, decision, or competing interpretation the page is meant to help them understand. The first reader-first IA pilot should therefore use Hsinchu baseball stadium, where the public dispute, procedural tracks, evidence boundaries, named statements, and chronology are explicit.

## What Changes

- Replace EZ WAY as the first reader-first **issue** pilot with the Hsinchu baseball-stadium dossier.
- Resolve the Hsinchu D1 order decision before changing its body order: either approve introduction/contents before the primary-document unit, or explicitly retain the existing document-first contract.
- Define a Hsinchu-specific reading map that preserves every existing public record, status, proof scope, limitation, attribution, canonical source URL, and legacy fragment.
- Add issue-oriented entry and contents navigation that helps a first-time reader distinguish the dispute, procedural status, evidence, named statements, chronology, analysis, and unresolved limits.
- Keep the published EZ WAY route as a process/information page; do not delete it or reinterpret it as an issue.
- Keep the existing homepage sections and seven metadata-only exclusions unchanged.
- Treat screen-reader, actual zoom, owner acceptance, and production release as separate acceptance gates; do not claim completion from static tests alone.
